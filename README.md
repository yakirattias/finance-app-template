# Stash — ריפו הנתונים שלך

הריפו הזה שומר את הנתונים שלך (תקציב, הוצאות, חיסכון) בקובץ אחד: `data/budget.json`.
הוא פרטי ושייך רק לך. האפליקציה עצמה רצה בכתובת:

**https://finance-app-flax-seven-97.vercel.app**

## הקמה (פעם אחת, כ-5 דקות)

1. **יצירת ריפו פרטי מהתבנית** — למעלה בדף: **Use this template ← Create a new repository**. בחר שם (למשל `my-finance`), סמן **Private** ולחץ **Create repository**.
2. **פתיחת האפליקציה** ← "אני חדש". היא תיתן לך קישור ליצירת טוקן עם ההרשאות הנכונות כבר מסומנות. רק בחר את הריפו שיצרת תחת **Only select repositories**.
3. **חיבור כרטיסים ובנקים** (לא חובה) — בהגדרות האפליקציה ← "חיבור כרטיסים ובנקים". בוחרים חברות, ממלאים פרטי כניסה, ומקבלים טקסט אחד שמדביקים כאן ב-**Settings ← Secrets and variables ← Actions ← New repository secret** בשם `BANK_CREDENTIALS`.

מאותו רגע העסקאות מתעדכנות כל בוקר ב-09:00, ובכל לחיצה על "עדכון עסקאות".

## אילו כרטיסים ובנקים נתמכים?

כאל, מקס, ישראכרט, אמריקן אקספרס, ביחד בשבילך, בהצדעה, ובנקים: לאומי, דיסקונט, מזרחי טפחות, הבינלאומי, מרכנתיל, אוצר החייל, מסד, יהב, פאג״י.
בנק הפועלים דורש לפעמים קוד SMS, ואז העדכון האוטומטי לא יעבוד.

**ויזה / מאסטרקארד / דיינרס** הן רשתות סליקה, לא חברות. בוחרים את מי שהנפיק את הכרטיס (כתוב על הכרטיס או בפירוט החודשי): כאל, מקס או ישראכרט.

## פרטיות ואבטחה

- פרטי הכניסה שמורים רק כ-Secret מוצפן בריפו **שלך**. אף אחד אחר — כולל מי ששלח לך את התבנית — לא יכול לקרוא אותם.
- המשיכה מהאתרים רצה ב-GitHub Actions **בחשבון שלך**, עם ספריית הקוד הפתוח [israeli-bank-scrapers](https://github.com/eshaham/israeli-bank-scrapers) בגרסה נעולה.
- הטוקן של האפליקציה נשמר רק בדפדפן שלך, ומוגבל לריפו הזה בלבד.
- מומלץ: בהגדרות האפליקציה אפשר לנעול בקוד בכל מכשיר.

## עדכונים

לא צריך לעשות כלום. האפליקציה ומנוע העדכון משותפים, וכל שיפור מגיע אליך אוטומטית.

## עצירה

רוצה להפסיק? מחק את ה-Secret `BANK_CREDENTIALS`, או את כל הריפו. הנתונים לא שמורים בשום מקום אחר.
